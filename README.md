# README for portfolio case

# АлАвто CRM — веб-система для шинного центра

Кейс для портфолио: внутренняя CRM и витрина для шинного центра с двумя филиалами.
Реальный проект, запущенный в продакшене на VPS (Docker), данные клиента обезличены.

## Задача

Шинный центр вёл учёт заказов и клиентскую базу в Excel: файл номенклатуры загружали
двумя филиалами по отдельности, записи дублировались, заказы путались между точками,
доступ сотрудников ничем не ограничивался.

## Что сделано

- **Каталог с подбором**: шины и диски с фильтрами (размер, сезон, разболтовка, вылет ET,
  ЦО), разноширокий подбор «спереди/сзади», пагинация, варианты наличия от поставщиков.
- **Кабинет сотрудника**: заказы (канбан-статусы «В пути/Завершён», позиции, задаток,
  автоматический остаток), клиенты, номенклатура с импортом Excel с предпроверкой,
  поставщики с приёмкой остатков по API (`X-API-Key`), черновики рассылок.
- **Филиалы и права**: заказы видят все, редактирует только филиал-создатель + админ;
  у клиентов раздельные базы; смена филиала клиента — только администратор.
- **Вкладка «Сотрудники»** (админ): добавление/удаление, смена логина, имени, пароля, филиала.
- **Карточки клиентов**: крупные карточки с ID (имя + 4 цифры телефона), счётчиком заказов
  (клик → история заказов), валидацией телефона (11 цифр, «+7»/«8»), удалением с защитой
  истории.
- **Идемпотентная защита от дублей**: ID клиента вычисляется автоматически, импорт Excel
  проходит превью до записи.

## Стек

- **Backend**: Python 3.12, FastAPI, SQLAlchemy 2 (async-совместимый стиль, `Mapped`),
  PostgreSQL 16, Alembic (8 миграций), JWT (python-jose), bcrypt (passlib), openpyxl.
- **Frontend**: ванильный JS (без фреймворков), CSS-дизайн в фирменном стиле, `<dialog>`,
  клиентский ресайз и шарпенинг фото товара (canvas).
- **Инфраструктура**: Docker Compose (nginx + FastAPI + PostgreSQL), healthcheck,
  автоматические миграции и сид при старте.

## Структура

```
backend/         FastAPI-приложение, Alembic-миграции, тесты pytest
frontend/        Статический SPA (index.html + app.js + styles.css), nginx.conf
compose.yaml     db + api + frontend, миграции и сид применяются при старте
```

## Запуск

```bash
cp .env.example .env        # заполните пароли
docker compose up -d --build
# каталог:  http://localhost:8080
# API docs: http://localhost:8000/docs
```

Демо-доступ после сида: `admin` (администратор), `anna` (сотрудник «АлАвто»),
`gleb` (сотрудник «Дискотека») — пароли задаются в `seed.py` для локальной демонстрации.

## Права доступа (кратко)

| Действие | Сотрудник филиала | Администратор |
|---|---|---|
| Просмотр заказов всех филиалов | ✔ | ✔ |
| Редактирование заказа | только своего филиала | ✔ |
| Клиенты | только своей базы | обе базы + смена филиала клиента |
| Сотрудники | ✖ | ✔ |
| Поставщики, ключи API | просмотр | ключи выдаёт админ |
